# Feature research

Generated by `ffpm research features` into `artifacts/feature-research/`:

- `feature-coverage.csv`
- `year-over-year-stability.csv`
- `incremental-value.csv`
- `feature-importance.csv`
- `research-summary.json`

Interpretation rules:

- Prefer features with adequate coverage before the target season.
- Require out-of-sample incremental value over baselines.
- Avoid target leakage and redundant collinear fields.
- Univariate correlation is not causation.

The methodology page summarises feature groups without overstating causality.
